Formularios en HTML

Texto

Campos de texto basicos: simple, con placeholder, obligatorio(required), de solo lectura (readonly) y deshabilitado (disabled).






Contacto

Campos especializados para datos de contacto: contraseña, correo electronico, telefono y URL, cada uno con su propio teclado y validacion en el navegador.





Numericos

Campos para valores numericos: un numero con limites (min/max) y un deslizador (range) para elegir un valor sentro de un rango.



Fecha y hora

Selectores nativos de fecha y hora: fecha, y hora combinadas, hora, semana del año y mes.






Seleccion

Controles de seleciion: elegir un color, marcar una casilla, elegir una opcion de un grupo de radios y subir un archivo.





Lista desplegables (select)

Listas desplegables con el elemento select: una opcion simple, una con valor preseleccionado (select), una agrupada con optgroup, una seleccion multiple (multiple) y una deshabilitada (disabled).
